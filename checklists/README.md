مستخرجة من استمارة الرقابة / جمع البيانات — المجالات 689.0 إلى 692.0
(4 مجالات رئيسية · 31 مجالًا فرعيًا · 141 بند رقابة).

| الملف | الوصف | الحجم |
|---|---|---|
| `muraijib-checklist-detailed.pdf` | النسخة التفصيلية: كل بند بترميزه مع خانات الحكم والشاهد | 9 صفحات A4 |
| `muraijib-checklist-summary.pdf` | النسخة المختصرة: ملخّص على مستوى المجالات الفرعية | صفحتان A4 |

## إعادة التوليد

```bash
cd src
python3 gen.py        # ينتج detailed.html و summary.html
node print.js         # يحوّلهما إلى PDF عبر Chromium
```

- `data.py` — مصدر البيانات (بنود الرقابة مرتّبة حسب الترميز الرسمي).
- `gen.py` — يبني صفحات HTML بتنسيق A4 مع تضمين خط Cairo.
- `print.js` — يطبع الصفحات إلى PDF مع ترقيم الصفحات.
