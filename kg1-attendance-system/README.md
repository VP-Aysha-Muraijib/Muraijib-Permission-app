# نظام متابعة وتحليل الحضور والغياب – روضة الخليف / KG1

Smart Attendance Analytics System (Excel) – قسم الروضة الأولى KG1، العام الدراسي 2026–2027.

## الملفات

| الملف | الوصف |
|---|---|

## البيانات المستوردة من قوائم Word

لكل طفل: رقم الطالب، الاسم، اسم ولي الأمر (مشتق من اسم الطفل بحذف الاسم الأول – يمكن تعديله)، أول رقم هاتف للأبوين، والأرقام الإضافية في خانة الملاحظات. رقم الهوية وتاريخ الميلاد والجنسية لم تُنقل لأنها خارج نطاق متابعة الحضور.

## القواعد المطبَّقة

- الخلية الفارغة لا تُحتسب حضورًا ولا غيابًا؛ فقط عند وضع ✓ في «تأكيد تسجيل اليوم» تُعتبر الخلايا الفارغة حضورًا (Default = Present بعد التأكيد).
- نسبة الحضور = (الحضور + التأخير) ÷ الأيام المسجَّلة فعليًا للطفل. لا تُحتسب العطلات (من الإعدادات) ولا الأيام غير المسجَّلة ولا ما قبل تاريخ الالتحاق.
- حدود التنبيه تُحتسب على الغياب بدون عذر فقط، وتُقرأ من ورقة الإعدادات (المعادلات و Conditional Formatting تعتمد على الأسماء `Thr_FollowUp` … `Thr_Critical`).
- الطفل غير «نشط» (منقول / منسحب) لا يدخل في الإحصائيات. الرقم الطلابي المكرر يُرفض ويُلوَّن.
- جميع الأوراق محمية بدون كلمة مرور؛ الخلايا الصفراء فقط قابلة للتعديل.

## إعادة البناء

```bash
pip install openpyxl
cd generator
python3 main.py ../KG1_Attendance_System_Demo.xlsx ../KG1_Attendance_System_Blank.xlsx ../KG1_Attendance_System_2026-2027.xlsx <مجلد ملفات Word للقوائم>
# التحقق (يتطلب LibreOffice لإعادة الحساب ثم):
python3 verify.py <ملف بعد إعادة الحساب>
```

ملاحظة: المعادلات كُتبت بدوال متوافقة مع Excel 2016+ (COUNTIFS / INDEX / MATCH / MAXIFS / MINIFS / SMALL كصيغ مصفوفية) بدلًا من FILTER/SORT/XLOOKUP لضمان العمل على جميع إصدارات Excel الحديثة وعلى LibreOffice.
