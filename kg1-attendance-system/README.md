# نظام متابعة وتحليل الحضور والغياب – روضة الخليف / KG1

Smart Attendance Analytics System (Excel) – قسم الروضة الأولى KG1، العام الدراسي 2026–2027.

## الملفات

| الملف | الوصف |
|---|---|
| `KG1_Attendance_System_2026-2027.xlsx` | **الملف الفعلي للاستخدام**: قوائم الأطفال الحقيقية للصفوف السبعة KG1-1 … KG1-7 (157 طفلًا) مستوردة من ملفات Word، بدون حضور مسجَّل بعد |
| `KG1_Attendance_System_Demo.xlsx` | نسخة ببيانات تجريبية (7 صفوف × 20 طفلًا وهميًا، 49 يومًا مسجَّلًا حتى 05/11/2026) تُظهر جميع مستويات التنبيه |
| `KG1_Attendance_System_Blank.xlsx` | النسخة الفارغة للاستخدام الفعلي (نفس النظام بدون أطفال أو حضور) |

## البيانات المستوردة من قوائم Word

لكل طفل: رقم الطالب، الاسم، اسم ولي الأمر (مشتق من اسم الطفل بحذف الاسم الأول – يمكن تعديله)، وأرقام هواتف الأبوين (حتى 4 أرقام) تُختار من قائمة منسدلة في خانة رقم التواصل. رقم الهوية وتاريخ الميلاد والجنسية لم تُنقل لأنها خارج نطاق متابعة الحضور.

## الشعارات والاعتماد

- الترويسة: شعار وزارة التربية والتعليم في الوسط، واسم الروضة أقصى اليمين وتحته «نطاق AD 2.3» (من الإعدادات). ملف الشعار الرسمي `generator/assets/moe_logo.png` (النسخة الذهبية أحادية اللون).
- التذييل: «يعتمد، نعيمة الكتبي» مع التاريخ أقصى اليمين، و«مديرة المدرسة: منى الغيثي» أقصى اليسار (في التقرير ولوحة المتابعة).
- خانة الطباعة في ورقة التقرير: تقرير يومي (مع قائمة غائبي اليوم) / أسبوعي / شهري (مع تفصيل الأيام) / فصلي / سنوي، لكل الصفوف أو صف محدد، مضبوط على A4.
- إدخال الحضور بأثر رجعي: خانة «الانتقال إلى تاريخ سابق» في كل ورقة صف + قوائم تواريخ منسدلة في اللوحة والحضور اليومي والتقرير.

## القواعد المطبَّقة

- الافتراضي حاضر: كل يوم دوام حتى تاريخ «الحصر مكتمل حتى» (فارغ = حتى اليوم) يُعتبر محصورًا والخلية الفارغة فيه = حاضر؛ الأيام بعده لا تُحتسب.
- نسبة الحضور = (الحضور + التأخير) ÷ الأيام المسجَّلة فعليًا للطفل. لا تُحتسب العطلات (من الإعدادات) ولا الأيام غير المسجَّلة ولا ما قبل تاريخ الالتحاق.
- حدود التنبيه تُحتسب على الغياب بدون عذر فقط، وتُقرأ من ورقة الإعدادات (المعادلات و Conditional Formatting تعتمد على الأسماء `Thr_FollowUp` … `Thr_Critical`).
- الطفل المنسحب: يُمسح رقمه واسمه من ورقة الصف فيخرج من الإحصائيات. الرقم الطلابي المكرر يُرفض ويُلوَّن.
- جميع الأوراق محمية بدون كلمة مرور؛ الخلايا الصفراء فقط قابلة للتعديل.

## إعادة البناء

```bash
pip install openpyxl
cd generator
python3 main.py ../KG1_Attendance_System_Demo.xlsx ../KG1_Attendance_System_Blank.xlsx ../KG1_Attendance_System_2026-2027.xlsx <مجلد ملفات Word للقوائم>
# التحقق (يتطلب LibreOffice لإعادة الحساب ثم):
python3 verify.py <ملف بعد إعادة الحساب>
```

ملاحظة: المعادلات كُتبت بدوال متوافقة مع Excel 2016+ (COUNTIFS / INDEX / MATCH / MAXIFS / MINIFS / SMALL كصيغ مصفوفية) بدلًا من FILTER/SORT/XLOOKUP لضمان العمل على جميع إصدارات Excel الحديثة وعلى LibreOffice.
