# input /

Put your Excel file here and name it **students.xlsx**

    input/students.xlsx

Two layouts are understood automatically:

**A. One sheet per class** (the MOE export)
Sheet name = the class (`5-1`, `5-2`, …), one student per line:

    MOUZA ALSAADI (stuf20210010402@moe.sch.ae) : KpOvWqE$jwCc

**B. A normal table** with the columns
`Class` | `Student Name` | `Email` | `Password`

Files placed in this folder are ignored by git and are never uploaded anywhere.
